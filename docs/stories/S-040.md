## User Story

As a security analyst, I want declarative YAML correlation rules that are validated on load.

## Acceptance Criteria

- [ ] YAML rule format specifying: name, entity_type, window, sources (with conditions), alert_severity
- [ ] Rules validated on load with clear error messages for syntax issues
- [ ] Schema validation for rule structure
- [ ] Rules accessible to correlation engine

## Deferred from S-003 Code Review

> **Security (from S-003 review — Security Reviewer, HIGH):**
> - Validate regex patterns in `SourceCondition.conditions` at YAML load time via `re.compile()`
> - Enforce max pattern length (512 chars) to bound compile-time cost
> - Enforce field name allowlist on `conditions` keys to prevent `__class__`-style probing
> - Consider using `regex` library with timeout for production regex matching (ReDoS defense)
