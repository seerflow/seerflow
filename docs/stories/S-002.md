## Technical Notes

### SeerflowEvent Fields (from architecture doc)

The architecture defines this exact struct at `docs/architecture-seerflow-2026-03-17.md:595`:

```python
class SeerflowEvent(msgspec.Struct, frozen=True, gc=False, tag=True):
    # Identity
    event_id: uuid.UUID
    timestamp_ns: int           # event time (nanoseconds since epoch)
    observed_ns: int            # pipeline receive time

    # Trace context (OTel)
    trace_id: str | None = None
    span_id: str | None = None

    # Severity (unified 0-6)
    severity_id: int = 1
    severity_text: str = "Informational"
    otel_severity: int = 9

    # Classification (ECS hierarchy)
    event_kind: str = "event"
    event_category: str = ""
    event_type: str = ""
    event_outcome: str = ""
    event_action: str = ""

    # OCSF numeric taxonomy
    category_uid: int = 0
    class_uid: int = 0
    type_uid: int = 0

    # Content
    message: str = ""
    body: Any = None

    # Source tracking
    source_type: str = ""
    source_id: str = ""
    log_source_category: str = ""
    log_source_product: str = ""
    log_source_service: str = ""

    # Drain3 metadata
    template_id: int = -1
    template_str: str = ""
    template_params: tuple[str, ...] = ()

    # Entity references (UUID5 strings)
    entity_refs: tuple[str, ...] = ()
    related_ips: tuple[str, ...] = ()
    related_users: tuple[str, ...] = ()
    related_hosts: tuple[str, ...] = ()

    # MITRE ATT&CK
    mitre_tactics: tuple[str, ...] = ()
    mitre_techniques: tuple[str, ...] = ()

    # Scores
    risk_score: float = 0.0
    confidence: float = 1.0
    anomaly_score: float = 0.0

    # Metadata
    attributes: dict[str, Any] = {}
    tags: tuple[str, ...] = ()
    raw_event: str = ""
    resource_attrs: dict[str, str] = {}
```

### Severity Scale

| severity_id | severity_text | OTel range | Syslog equivalent |
|-------------|--------------|------------|-------------------|
| 0 | Trace | 1-4 | 7 (debug) |
| 1 | Informational | 5-8 | 6 (info) |
| 2 | Notice | 9-12 | 5 (notice) |
| 3 | Warning | 13-16 | 4 (warning) |
| 4 | Error | 17-20 | 3 (error) |
| 5 | Critical | 21-24 | 2 (critical) |
| 6 | Fatal | — | 0-1 (emerg/alert) |

### Performance Targets

- Struct creation: <1μs (4x faster than dataclasses)
- msgpack serialization: ~2μs per event
- Memory per instance: ~400 bytes
- With `gc=False`: saves 16 bytes per instance, GC pause drops 75x

### Key Design Decisions

1. **`frozen=True`** — immutable after creation. Pipeline stages create new events via `msgspec.structs.replace()` instead of mutation.
2. **`gc=False`** — removes from cyclic GC tracking. Safe because SeerflowEvent doesn't hold references to itself. Saves 16 bytes + eliminates GC pause per event.
3. **`tag=True`** — includes type tag in msgpack serialization for polymorphic deserialization.
4. **`tuple` not `list`** — tuples are immutable (required by frozen), hashable, and slightly smaller.
5. **`dict` for `attributes`/`resource_attrs`** — msgspec allows mutable default `{}` in frozen structs (it's the dict itself that's default, not its contents). These are pass-through for source-specific metadata.

## Architecture Context

- **Hot path position:** SeerflowEvent is created once per log line and passed through all 12 pipeline stages. It's the most frequently allocated object in the system.
- **Serialization:** msgpack for storage (BLOB column), JSON for REST API responses. Both handled natively by msgspec.
- **Immutability pattern:** `msgspec.structs.replace(event, risk_score=0.8)` creates a new event with one field changed. All pipeline stages use this instead of mutation.
- **This is S-002's only concern:** Define the struct + severity mapping. No parsing, no entity extraction, no storage — those are S-003 through S-015.

## Out of Scope

- `Alert` and `CorrelationRule` structs (S-003)
- Query/filter dataclasses (S-003)
- Parsing logic that creates events (S-012, S-014)
- Storage that persists events (S-006)

## Brainstorm Notes

1. **`body: Any = None` with `gc=False`** — safe; gc=False only removes struct wrapper from cyclic GC, not referenced objects
2. **`dict` default in frozen struct** — msgspec copies default on creation; mutation-safe
3. **`SeverityLevel` IntEnum** — add for type safety + text mapping; struct keeps `severity_id: int` for msgspec compat
4. **`msgspec.structs.replace()`** — test functional update pattern
5. **`uuid.UUID`** — msgspec handles natively for msgpack + JSON
6. **No `from __future__ import annotations`** — Python 3.13 native
7. **Benchmark** — `time.perf_counter_ns()`, 10K creates < 10ms, no pytest-benchmark dep
8. **File location** — `src/seerflow/models/event.py`, re-export in `__init__.py`
