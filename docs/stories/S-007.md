# S-007: SQLite backend — event queries, filtering, pagination, FTS5

**Linear:** [SEE-11](https://linear.app/seerflow/issue/SEE-11) | **Epic:** EPIC-006: Storage | **Priority:** Must Have
**Points:** 5 | **Sprint:** 1 — Foundation | **Dependencies:** S-006

## User Story

As the dashboard, I want indexed event queries so that I can display events filtered by time, source, severity, and entity.

## Acceptance Criteria

- [ ] Query by time range with index
- [ ] Filter by source_type, severity_id, template_id
- [ ] Filter by entity_uuid (via entity_events junction table)
- [ ] FTS5 full-text search on message field
- [ ] Pagination with configurable page size
- [ ] Query response <500ms for 100K events
