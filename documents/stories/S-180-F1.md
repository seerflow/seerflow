## Scope

2. Copy every file from `documents/seerflow-guide-staging/` (in the seerflow repo) into its target path in seerflow-guide per the file-map in `documents/seerflow-guide-staging/README.md`.
3. Rename `drift_check/` → `scripts/` and `guide/` → `docs/` during the copy.
4. Merge the relevant `pyproject.toml` keys into the existing seerflow-guide pyproject (do **not** wholesale-replace).
5. Wire the new nav entries (api, quickstart, frontend, retros) into `seerflow-guide/mkdocs.yml`.
6. Add a "Retrospective" pointer line to `seerflow/docs/stories/S-139.md` and an "EPIC-DOC retrospective" closing subsection to `seerflow/docs/sprint-plan-seerflow-2026-03-17.md` — verify they are tracked on the target branch (in the local snapshot they were excluded via `.git/info/exclude`).
7. Confirm `mkdocs build --strict` passes.
8. Confirm the staged `docs-drift` workflow passes on the introducing PR (dogfood).

10. Transition SEE-142 → Done.
